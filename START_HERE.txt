QUICK START (5 Minutes)
================================================================================

STEP 1: Install Dependencies
------------------------------
Option A (Windows):
  Double-click: setup.bat

Option B (All Systems):
  Open terminal/command prompt in root directory and run:
  
  cd server && npm install
  cd ../admin && npm install  
  cd ../portfolio && npm install
  cd ..


STEP 2: Configure Backend
---------------------------
1. Go to server/ folder
2. Copy .env.example to .env
3. Edit .env and add your MongoDB connection
   
   For local MongoDB:
     MONGO_URI=mongodb://localhost:27017/portfolio_db
   
   For MongoDB Atlas:
     MONGO_URI=mongodb+srv://username:password@cluster.mongodb.net/portfolio_db


STEP 3: Start Backend Server
-----------------------------
Open terminal:
  cd server
  npm run dev

✅ Server will run on http://localhost:5000


STEP 4: Create Admin Account
-----------------------------
Open a NEW terminal:

Using curl (Mac/Linux):
  curl -X POST http://localhost:5000/api/auth/register \
    -H "Content-Type: application/json" \
    -d '{"username":"admin","email":"admin@example.com","password":"password123"}'

OR use Postman/Thunder Client:
  - POST to: http://localhost:5000/api/auth/register
  - Body (JSON):
    {
      "username": "admin",
      "email": "admin@example.com", 
      "password": "yourpassword"
    }


STEP 5: Start Admin Panel
--------------------------
Open a NEW terminal:
  cd admin
  npm run dev

✅ Admin will run on http://localhost:3001


STEP 6: Login & Start Managing
-------------------------------
1. Go to http://localhost:3001
2. Login with your credentials
3. Start adding projects, viewing contacts, etc.

================================================================================
TROUBLESHOOTING:
================================================================================

Backend won't start?
→ Check if MongoDB is running
→ Verify MONGO_URI in server/.env

Can't login to admin?
→ Make sure backend is running
→ Verify admin account was created
→ Check browser console for errors

Port already in use?
→ Change PORT in server/.env
→ Or kill the process using the port
