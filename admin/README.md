# Portfolio Admin Panel

React-based admin panel for managing the portfolio website.

## Features

- Dashboard with statistics
- Manage projects (CRUD operations)
- View and manage contact messages
- Manage skills
- Edit about section
- Secure authentication with JWT

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

The admin panel will run on `http://localhost:3001`

## First Login

1. Make sure the backend server is running on `http://localhost:5000`
2. Create an admin account by registering through the backend API (see server README)
3. Login with your credentials

## Usage

- **Dashboard**: View overview statistics
- **Projects**: Add, edit, delete portfolio projects
- **Contacts**: View and manage incoming messages
- **Skills**: Manage your skills and expertise
- **About**: Edit the about section content
